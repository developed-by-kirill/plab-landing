# Лендинг PLab

Актуальная страница: dist/index.html. Запускайте локальный HTTP-сервер из dist/ для предпросмотра. Все ресурсы локальные, внешние библиотеки не требуются.

- portal-shader.js и portal.js — эффект Portal Field.
- style.css — адаптивная чёрно-синяя палитра и стеклянные элементы.
- gallery.js — готовая галерея; gallery-runtime.js — её исходный код поведения.
- gallery/ — пять реальных снимков приложения.
- downloads/ — приложение, инструкция, сведения о выпуске.

Порядок публикации и адреса — в PUBLICATION.md. Изменения сайта не пересобирают приложение: для нового выпуска сначала экспортировать и проверить Windows-сборку.
